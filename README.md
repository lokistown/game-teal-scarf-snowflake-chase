# Teal Scarf Snowflake Chase

Help Loki and Pip catch swirling winter snowflakes in a woven basket while dodging chilly gusts of wind. A cozy pixel-art mini-game set in Loki's Town.

**How to play:** Use Left/Right arrow keys or touch the sides of the screen to move the basket.

▶️ Play it: https://lokistown.github.io/games/teal-scarf-snowflake-chase/
